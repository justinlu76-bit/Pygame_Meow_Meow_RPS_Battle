🐱 Meow Meow RPS Battle

貓咪剪刀石頭布大戰 | Cat Rock Paper Scissors Battle

📖 專案介紹 | Project Introduction


《貓咪剪刀石頭布大戰》是一款使用 Python 與 Pygame 開發的互動式小遊戲。

玩家可以透過滑鼠選擇剪刀、石頭或布，與電腦進行對戰。遊戲結合可愛的貓咪主題、圖形化介面與隨機出拳機制，讓傳統的剪刀石頭布變得更加生動有趣。

透過這次專案，練習 Python 程式邏輯、條件判斷、隨機數生成，以及 Pygame 的圖形介面與滑鼠事件處理。


Meow Meow RPS Battle is an interactive Rock-Paper-Scissors game developed using Python and Pygame.

Players can choose rock, paper, or scissors using their mouse and compete against the computer. With a cute cat-themed design, graphical interface, and randomized computer choices, this project makes the classic game more fun and engaging.

This project focuses on practicing Python programming logic, conditional statements, random selection, graphical interface design, and mouse event handling.

🎮 遊戲玩法 | How to Play


啟動遊戲，進入貓咪剪刀石頭布對戰畫面。

使用滑鼠選擇剪刀、石頭或布。

電腦會隨機選擇出拳。

系統自動比較雙方選擇並判斷勝負。

獲勝則得分，可無限挑戰。


Launch the game and enter the battle screen.

Click Rock, Paper, or Scissors using your mouse.

The computer randomly selects its move.

The game compares both choices and determines the winner.

View the result!
